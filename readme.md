# ⚡ Materiais Elétricos

Site profissional desenvolvido para apresentação e divulgação de **materiais elétricos**, com foco em uma experiência moderna, responsiva e fácil de navegar.

## 📋 Sobre o projeto

O projeto consiste em um catálogo online de materiais elétricos, permitindo apresentar produtos de forma organizada e visualmente atrativa.

O site foi desenvolvido para funcionar em **computadores, tablets e celulares**, oferecendo uma interface moderna e adaptável a diferentes tamanhos de tela.

## 🚀 Como executar o projeto

Clone o repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Entre na pasta:

```bash
cd NOME_DO_PROJETO
```

Depois, abra o arquivo `index.html` no navegador ou utilize o **Live Server** no VS Code.
